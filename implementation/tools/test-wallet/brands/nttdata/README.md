# The NTT DATA brand of the test wallet

A look for the EDTP test wallet, for demonstrations NTT DATA gives, with NTT DATA's permission
(21 November 2026, `CLAUDE.md` §6.22). Applied with `build.sh --brand nttdata`.

**It changes how the app looks and nothing else.** The modified-build banner stays on every screen,
the build is still signed with our `OU=TEST ONLY` key under our own `applicationId`, and
`BuildConfig.EDTP_DEVIATIONS` still names what is compiled in. It is not an NTT DATA product and not
the EUDI Reference Wallet, and must not be presented as either.

| | |
|---|---|
| `source/nttdata-logo-futureblue.png` | NTT DATA's logo, Future Blue on a transparent background, 750 × 500, as NTT DATA provided it, unaltered |
| `res/` | What the build copies over the flavour's resources: the logo and its emblem (the ring) for the splash and the header, a white copy of each for the dark theme, and the launcher icon. Generated by `make-assets.mjs`, which measures the emblem from the image; committed |
| `colors.txt` | The theme: NTT DATA's Future Blue (`#0072BB`, read from the logo file), tints of it, white, black, and the same neutral greys as `brands/fnmt` |

The logo is NTT DATA's and is used here with its permission, for its own demonstrations. It is not
licensed with the rest of this repository.

## The build it was made for

W9's configuration with this look, installed alongside W9 (`deviations.md`, *W9N*).
