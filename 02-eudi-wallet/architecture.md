# EUDI Wallet Architecture Notes

**Status:** [SPECIFICATION]

Key reusable concepts from ARF 3.0 include:

- Wallet Provider and Wallet Unit lifecycle;
- PID and Attestation Providers;
- QEAA, PuB-EAA and non-qualified EAA categories;
- Authentic Sources;
- Relying Parties, Services and Instances;
- Registrars;
- Access Certificate Authorities and registration certificates;
- Wallet Instance Attestation (WIA) and Key Attestation (KA);
- WSCA/WSCD security architectures;
- LoTE/Trusted List based trust mechanisms.

These concepts should be mapped against the future EUBW architecture rather than copied automatically.
