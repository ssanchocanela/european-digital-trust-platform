# EUDI Wallet Issuance

**Status:** [SPECIFICATION]

ARF 3.0 uses OpenID4VCI as the standard interface for attestation issuance and as the baseline PID issuance interface.

This is a primary foundation for the proposed **Issuance as a Service** product.

Topics to analyse:

- credential offers and browser-initiated journeys;
- issuer metadata;
- wallet/issuer authentication;
- proof of possession and key binding;
- supported credential formats;
- issuer trust and registration;
- credential status/revocation;
- rulebooks and schemes;
- lifecycle/audit requirements.
