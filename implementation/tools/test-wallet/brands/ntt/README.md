# The NTT DATA brand of the test wallet

A look for the EDTP test wallet, for demonstrations delivered to NTT DATA, at NTT DATA's request
(`CLAUDE.md` §6.22). Applied with `build.sh --brand ntt`.

**It changes how the app looks and nothing else.** The modified-build banner stays on every screen,
the build is still signed with our `OU=TEST ONLY` key under our own `applicationId`, and
`BuildConfig.EDTP_DEVIATIONS` still names what is compiled in. It is not an NTT DATA application and
must not be presented as one.

| | |
|---|---|
| `source/logo_ntt_data.png` | NTT DATA's logo (blue emblem and "NTT DATA" wordmark on white), as provided by the team, unaltered |
| `res/` | What the build copies over the flavour's resources: the emblem for the splash and the launcher icon, the full logo for the header, and a dark-theme copy. Generated by `make-assets.mjs`, committed |
| `colors.txt` | The theme: NTT DATA's blue (`#0072BB`, measured in the logo's pixels), white, black, tints of that blue and neutral greys |

The wordmark is blue, not black, so the dark-theme copy is the same as the light one — the brand
blue stays the brand blue on either background, which is why `drawable-night-xxhdpi` matches
`drawable-xxhdpi`.

The logo is NTT DATA's and is used here with its permission, for its own demonstrations. It is not
licensed with the rest of this repository.
