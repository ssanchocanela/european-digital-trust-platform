# EUDI Wallet Presentation

**Status:** [SPECIFICATION]

ARF 3.0 supports proximity and remote presentation. Remote presentation includes OpenID4VP and the W3C Digital Credentials API, with custom URI mechanisms also covered.

This is the primary foundation for **Verification as a Service**.

The service should abstract request creation, RP authentication/registration, wallet invocation, response validation, trust validation, selective disclosure handling and business-system integration.
