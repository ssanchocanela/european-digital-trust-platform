# The FNMT-RCM brand of the test wallet

A look for the EDTP test wallet, for demonstrations delivered to FNMT-RCM, at FNMT-RCM's request
(decided 7 October 2026, `CLAUDE.md` §6.22). Applied with `build.sh --brand fnmt`.

**It changes how the app looks and nothing else.** The modified-build banner stays on every screen,
the build is still signed with our `OU=TEST ONLY` key under our own `applicationId`, and
`BuildConfig.EDTP_DEVIATIONS` still names what is compiled in. It is not an FNMT-RCM application and
must not be presented as one.

| | |
|---|---|
| `source/logo_fnmt_30mm_bn.png` | FNMT-RCM's logo, the black-and-white variant, unaltered, from the PNG pack at <https://www.fnmt.es/prensa/identidad-corporativa> (fetched 7 October 2026) |
| `res/` | What the build copies over the flavour's resources: the logo and its emblem for the splash and the header, a white copy of each for the dark theme, and the launcher icon. Generated by `make-assets.mjs`, committed |
| `colors.txt` | The theme: FNMT-RCM's blue (`#1a3b88`), white, black, and neutral greys |

The logo is FNMT-RCM's and is used here with its permission, for its own demonstrations. It is not
licensed with the rest of this repository.
