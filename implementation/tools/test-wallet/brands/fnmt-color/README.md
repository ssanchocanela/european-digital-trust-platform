# The FNMT-RCM colour brand of the test wallet

The same as [`../fnmt`](../fnmt/README.md) — a look for the EDTP test wallet, for demonstrations
delivered to FNMT-RCM, at its request — but from FNMT-RCM's **colour** logo, as it asked on
15 October 2026. Applied with `build.sh --brand fnmt-color`.

**It changes how the app looks and nothing else.** The modified-build banner stays on every screen,
the build is still signed with our `OU=TEST ONLY` key under our own `applicationId`, and
`BuildConfig.EDTP_DEVIATIONS` still names what is compiled in. It is not an FNMT-RCM application and
must not be presented as one.

| | |
|---|---|
| `source/logo_fnmt_30mm_color.png` | FNMT-RCM's logo, the colour variant, unaltered, from the PNG pack at <https://www.fnmt.es/prensa/identidad-corporativa> |
| `res/` | The logo and its emblem for the splash and the header, the launcher icon (the blue emblem on white), and a dark-theme copy whose black lettering is white. Generated by `make-assets.mjs`, committed |
| `colors.txt` | The theme: the logo's blue (`#00539f`, measured in its pixels), white, black, tints of that blue and neutral greys |

The logo is FNMT-RCM's and is used here with its permission, for its own demonstrations. It is not
licensed with the rest of this repository.
